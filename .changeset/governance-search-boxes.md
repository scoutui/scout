In the governance form, Package or component and Superseded by are now search boxes. Each component shows its package beside it, with the best matches first and, among those, the most used in each repo's latest scan. Selecting a package searches only that package, and it stays selected for the next record. Its All of row marks the whole package, and the line under the field says how many components that is. In Package or component, rows that can't take a new record are dimmed and say why. Create now keeps the form open for the next record and says what was added, and Cancel then reads Close. For a few minutes after upgrading, while the dashboard rebuilds its stored results, the search boxes have nothing to offer.
