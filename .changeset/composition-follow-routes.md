A component's **Composition** tab now follows a route as far as it goes. Selecting a box opens everything that renders it, including components already shown nearer, which are marked as repeats, so one page shows routes that used to need a visit to another component's page. A line on the route shows how many times one component renders the next, such as **×3**, and a route that loops back shows the component it returns to as a greyed box. The link keeps the whole route you opened.
