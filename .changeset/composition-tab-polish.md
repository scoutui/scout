A component's **Composition** tab is easier to read. The render tree's caption is larger, with each sentence on its own line and the counts and the component's name set apart. Chips on the render tree widen to fit longer names when there's room. **Hide lists** and **Show lists** now sit beside the zoom buttons. The lists drop their explanatory line, so each shows more rows, and their button reads **Show all** with the list's total. A long component name in an empty list now wraps instead of being cut off.
