The repo page's components table has a details panel beside it. Click a row, or press Enter or Space on it, to see the component's replacement or retirement, how many other repos use it, its most-set props and values, and the packages that use it most, each linking to the usage page already filtered. ↑ and ↓ move between components, and the component's name still opens its usage page. On tablets, phones and narrower windows the details open in a sheet you can swipe down to close. In the **since previous scan** view, each component's change in uses now has its own **Change** column.
