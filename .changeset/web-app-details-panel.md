The repo page's components table has a details panel beside it. Select a row to see the component's replacement or retirement, how many other repos use it, a chart of its uses or its migration, its most-set props and values, and the packages that use it most, each linking to its usage already filtered. ↑ and ↓ move between components. In a narrow window or on a phone, the details open in a sheet. Component names get more room in the table, the **since previous scan** view has its own **Change** column, and a deprecated component's replacement is easier to spot.
