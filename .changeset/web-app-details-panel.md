The repo page's components table has a **Change** column with each component's change since the previous scan, and a details panel beside it. Click a row, or press Space, to see the component's replacement or retirement, how many other repos use it, its most-set props and values, and the packages that use it most, each linking to the usage page already filtered. ↑ and ↓ move between components, and the component's name still opens its usage page. On smaller screens the details open in a drawer, and on tablets and phones in a sheet you can swipe down to close.
