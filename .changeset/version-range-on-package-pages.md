The packages list, package pages and a component's page across repos now show the versions in use as a range, such as `3.1.0 – 4.2.0`, instead of a count or a version bar. The version bar and the coloured dots in the **Used in** tables are gone: they marked the highest version found in your scans, which isn't necessarily the newest one published. Sorting the **Used in** tables by **Version** now orders versions correctly, so `1.5.0` comes before `1.14.0`.

Chart pages now have the same back link above the title as other detail pages, in place of the `Charts / <chart name>` trail.
