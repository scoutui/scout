The repos list has a **Last scan** column, showing when the dashboard received each repo's latest scan, and lists the most recently scanned repos first. **Committed** stays beside it. The branch and commit now sit under the repo's name, so a long branch name no longer pushes the other columns off the edge. **Changes** always reads in words, such as **+3 added · −16 removed**, at every width, and the filter button now reads **Changed since previous scan**. On a phone, each repo starts with when it was scanned and spells out what changed since its previous scan.
