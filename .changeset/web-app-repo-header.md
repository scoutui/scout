The repo page has a shorter header. Under the repo's name, one status line shows the repo's git remote, the commit and branch, how many deprecated components are in use, what changed since the previous scan (for example `+3 added · −1 removed · 4 changed since previous scan`), and, when the scan couldn't see everything, "Some uses may be missing" with a button that lists the gaps. ‹ and › beside the scan button step to the previous and next scan, and the scan button's menu lists recent scans followed by the scan ID, package count and scanner version. On an older scan, a "Back to latest" button sits beside the scan button. Settings is now a labelled button in the header instead of an item in the "⋯" menu.
