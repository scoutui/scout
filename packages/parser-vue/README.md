# @scoutui/parser-vue

Finds the components used in Vue single-file components (`.vue` files) for the [Scout](https://scoutui.dev) CLI: the components and web components in each template, where they're imported from, and the props passed.

This package is internal and isn't published. The CLI bundles it, so a change needs a `@scoutui/cli` changeset. [Framework support](https://scoutui.dev/docs/reference/framework-support) describes what a scan reads in Vue code.
