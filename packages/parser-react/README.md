# @scoutui/parser-react

Finds the components used in React code (`.jsx` and `.tsx` files) for the [Scout](https://scoutui.dev) CLI: each element, the component that renders it and the props passed.

This package is internal and isn't published. The CLI bundles it, so a change needs a `@scoutui/cli` changeset. [Framework support](https://scoutui.dev/docs/reference/framework-support) describes what a scan reads in React code.
